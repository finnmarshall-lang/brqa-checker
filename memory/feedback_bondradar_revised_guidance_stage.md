BR stages between IPTs and Spread Set include:

1. `IPTs` — first level shown, wide, source-labelled `IPTs`.
2. `Guidance` — first tighter marketing range, source-labelled `Guidance`.
3. `Revised guidance` — subsequent tightening/widening moves within the guidance phase. Source labels these `Revised guidance` (or `Guidance revised at X` / `Revised price guidance`). BR headline follows suit.
4. `Book update` — when the level DOES NOT move and only the book figure is new. Do not use this at a revision.
5. `Spread set` / `Final terms` / `Launched` / `Allocations` / `Priced` — later stages.

**Correct headline for a revised-guidance update:**
- `** ASFINAG EUR500m 5y WNG: Revised guidance MS+9bp area` (level moved from MS+11bp area to MS+9bp area, book figure also updated)

**Wrong for the same update:**
- `** ... : Book update` — implies level unchanged, but the level moved from 11 to 9.
- `** ... : Guidance MS+9bp area` — reads like first-time guidance; misses the "revision" context.

**Why:** Finn on ASFINAG EUR500m 5y WNG (id 14640112): source announced `€€€ Asfinag EUR 500m (no-grow) 5yr Benchmark - Revised guidance €€€` with `Guidance revised at MS+9 area` (moved from MS+11bp area). BR headline said `Book update`. I proposed `Guidance MS+9bp area`. Finn: "this is revised guidance". Correct stage word is `Revised guidance`.

**How to apply:**

1. On any post-Guidance stage update, before choosing between `Book update` / `Revised guidance` for the headline, compare the new level to the previous stage's level:
   - Level unchanged, only book figure new → `Book update` (level embed optional; see [[bondradar-headline-level-optional]]).
   - Level moved (tightened OR widened) → `Revised guidance <new level>`. This applies whether or not a book figure is also disclosed in the same update.
2. Match against source vocabulary: `Revised guidance`, `Guidance revised at`, `Revised price guidance`, `Guidance updated to` are all signals for the revised-guidance stage.
3. The body still opens with the standing `Guidance is <new level> for …` paragraph — that's fine; the stage word is derived from the update's revision-vs-reiteration character, not the body opener (see [[bondradar-headline-stage-by-update]]).
